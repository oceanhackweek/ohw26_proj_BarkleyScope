# Folger Passage temperature — anomaly pipeline

Monthly sea-water temperature anomalies for two Ocean Networks Canada stations in
Barkley Sound, off western Vancouver Island: **Folger Pinnacle** (25 m, 2011–2026) and
**Folger Deep** (98 m, 2016–2026). The question it answers is how unusually warm or cold
each month was relative to what is normal for that month at that depth, and how far
back the record supports saying so.

Figures follow the NOAA PSL marine-heatwave time-series style: monthly anomaly bars with
the 90th/95th/99th percentiles of the anomaly distribution marked, and exceedances
coloured.

**This is a coverage-first pipeline.** A quarter of the Pinnacle record is missing, so
every step reports what it kept and what it dropped, and every figure shows gaps as gaps
rather than interpolating through them.

## Requirements

Python 3.9+, with:

```bash
pip install pandas matplotlib
```

`pandas >= 2.0` (uses `format="ISO8601"`) and `matplotlib >= 3.3` (uses `labelcolor` in
legends). Developed and tested on Python 3.14.6, pandas 3.0.5, matplotlib 3.11.1.

## Workflow

```
   ../folger/*.csv                    ONC "clean, averaged" hourly scalar export
        |                             (# preamble + 4 bare columns)
        v
   read_csv() / inspect()             parse preamble -> time-indexed frame
        |                             inspect() also prints columns, time range,
        |                             integrity checks, regularity, gaps > 7 d
        v
   to_daily(min_hours=18)             hourly -> daily mean
        |                             under-threshold days kept, flagged ok=False
        v
   to_monthly(min_days=15)            daily -> monthly mean
        |                             trailing partial month dropped vs the calendar
        +----------------+----------------+
        |                                 |
        v                                 v
   climatology()                    common_baseline(a, b)
   12 calendar-month means          restrict two sites to months usable
        |                           at BOTH, then rebaseline each
        v                                 |
   anomalies()  -> anom_C                 v
        |                            plot_combined()
        +--> plot_coverage()         3 panels, one shared time axis
        +--> plot_anomalies()
```

Nothing in the pipeline cleans, fills, or interpolates. NaNs and QC flags arrive as ONC
wrote them, so the gap accounting describes the file rather than a choice made here.

## Quick start

```bash
cd data/folger_taylor
python make_figures.py                  # all stations + combined figure, into this folder
python make_figures.py --station deep   # one station only
python make_figures.py --outdir /tmp/x  # write elsewhere
python make_figures.py --no-report      # skip the printed inspection report
python make_figures.py --help
```

One command regenerates all ten outputs from nothing but the source CSVs. Each run first
prints a per-file inspection report — station metadata, columns, QC flags, time range,
integrity checks, sampling regularity, and gaps longer than seven days — so the state of
the input is on the record beside the output.

## Library API

Every function takes a path or a frame; none hardcodes a station.

| Function | Purpose |
|---|---|
| `read_header(path)` | parse the ONC `#` preamble into a dict |
| `read_csv(path)` | load one export as a time-indexed frame, unmodified |
| `inspect(path)` | load, print the full first-look report, return the frame |
| `sampling_regularity(df)` | value-count the spacing between timestamps |
| `gap_table(df, min_days=7)` | runs of missing valid data longer than `min_days` |
| `to_daily(df, min_hours=18)` | hourly → daily mean with a completeness rule |
| `to_monthly(daily, min_days=15)` | daily → monthly mean; drops a partial trailing month |
| `climatology(monthly)` | mean, SD and year count per calendar month |
| `anomalies(monthly, clim)` | monthly anomaly against that climatology |
| `common_baseline(a, b)` | restrict two sites to months usable at both, rebaseline each |
| `plot_coverage(monthly)` | bar chart of valid days per month |
| `plot_anomalies(anom)` | one station's anomaly bars with percentile thresholds |
| `plot_daily_series(series)` | daily means for one or more stations on one axis |
| `plot_comparison(a, b, ...)` | two stations, stacked anomaly panels, shared y-scale |
| `plot_combined(series, panels)` | daily means above one anomaly panel per station |

```python
import onc_folger as onc

df    = onc.inspect("../folger/<file>.csv")   # loads, prints the report, returns the frame
daily = onc.to_daily(df, min_hours=18)
mon   = onc.to_monthly(daily, min_days=15)
anom  = onc.anomalies(mon, onc.climatology(mon))
onc.plot_anomalies(anom, path="out.png", dpi=200)
```

## Using it on other data

Edit the `STATIONS` block near the top of `make_figures.py` and nothing else. Each entry
needs a display label and a path to an ONC "clean, averaged" scalar CSV; depth, station
code and instrument are read from that file's own preamble. Thresholds sit in one line
beneath (`MIN_HOURS, MIN_DAYS, DPI = 18, 15, 200`), and `COMPARE = None` skips the
two-site figure.

New exports come from ONC's Oceans 3.0 data search (<https://data.oceannetworks.ca>):
choose a station and Temperature, then "Average" with a 1-hour resample, "Clean" QC and
NaN gap fill. The reader expects that format — a `## END HEADER` line followed by four
positional columns (`time, value, qc_flag, count`) and ISO-8601 UTC timestamps. Another
ONC station works unchanged; a different provider needs its own reader, though
everything downstream of `read_csv` still applies.

## What the record shows

- **The two depths have opposite seasonal cycles.** Pinnacle (25 m) is warmest in
  autumn, Deep (98 m) in winter — their climatologies are uncorrelated (r = +0.03),
  consistent with summer upwelling. A climatology from one depth must never be used for
  the other.
- **Their anomalies nonetheless move together** (r = +0.85 across the 89 common months),
  so departures from each site's own seasonal cycle are shared through the water column.
- **The warmest months are 2014–2016** — the NE Pacific "Blob" and the 2015–16 El Niño —
  which is an independent check that the pipeline is behaving, since nothing in the code
  knows about them.

**Read `METHODS.md` before using these numbers.** It records the baseline choices and
six limitations, including two that change how the figures should be read: the baseline
contains the very events it is used to measure, and a fixed percentile threshold detects
**no summer events at either site** — which is a property of the threshold, not evidence
that summer marine heatwaves do not occur here.
